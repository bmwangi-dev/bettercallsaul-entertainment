# Better Call Saul Entertainment

Website for Better Call Saul Entertainment — movie shop & cyber café.

Plain HTML/CSS/JS, no build step. Pages: `index.html` (home), `about.html`, `reservation.html`.

## Editing contact details

Open `main.js` and update the `SHOP` block at the top (WhatsApp, phone, email, location, opening hours). Every button on all three pages reads from it.
